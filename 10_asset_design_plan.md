# Visual Asset Design Plan

## Production scope

- Animation shots analyzed: 66
- Master characters: CHAR_01 / Ah Lim (48 shots), CHAR_02 / Ah Da (51 shots)
- Supporting-character appearances: 1–2 shots each
- Most-used environment: LOC_01 classroom (44 shots)
- Location-schema correction: add LOC_06 basketball court and LOC_07 school corridor. The court is visually distinct from LOC_02; the corridor is distinct from LOC_01 and LOC_04.

## Asset-production order

1. Lock the two master characters before any shot generation.
2. Build the classroom master layout and reusable desk/chair system.
3. Create gate, canteen, hospital, and courtyard location packs.
4. Build the seven minimal supporting-character packs.
5. Build hero props and action-safe pose references.

## Character master principles

The source deliberately uses simplified line art with occasional stylistic variation. Canonical animation designs should preserve silhouette, hair, face geometry, uniform, and green trousers; expression and pose are variable. Do not merge the hospital elder’s facial design into Ah Lim’s afterlife/student appearance.

## Shot-driven coverage matrix

### Camera and pose coverage

- Primary shot sizes are MS (27) and CU (25); both main character packs require face-first talking reference coverage.
- Wide/WS shots require robust full-body and environment references, particularly for classroom, gate, courtyard, and basketball court.
- Key Ah Lim expressions: shock/confusion (3–8, 10–13), laughter (9, 14), warmth (16–18), hunger/nostalgia (27–31), bittersweet farewell (32–33).
- Key Ah Da expressions: exuberant greeting (4–7), explanatory/talking (10–18), nostalgic storytelling (19–26), amused eating (29–30), sad farewell/crying (31–35).
- Key actions: waking, pointing, simple running, eating, crying, waving, standing on desk, seated window reflection, mattress rest, basketball jump.

## Generation guardrails

- Use master-character sheets as the primary image reference for every shot; use original panels as pose/composition references only.
- Maintain 2D monochrome-line-art style with restrained flat accents: white shirts, medium-green trousers, pale skin, blue used only for Jenny/May/Anna.
- Avoid adding logos, modern objects, crowd details, or unshown props.
- Generate [INDISTINCT CHATTER] shots with non-specific mouth movement/room murmur only; never synthesize words.
- Keep fast movement to one primary action: Ah Da’s run, Li Jie’s joyful run, Anna’s basketball shot, and the final run each need separate stable clips.

## Asset acceptance checklist

- Master face and full-body sheets approved for CHAR_01 and CHAR_02.
- Classroom layout approved from all seven required views.
- LOC_06 and LOC_07 added to the production location schema before final shot prompts.
- Props match source silhouette and color constraints.
- Supporting-character packs only cover their actual vignette needs.
- Every asset ID in the manifest has at least one original-panel reference.
